# TaskFlow — Laboratorio N° 07 (Experiencias 1 a 6)

Cada carpeta es un proyecto de React con Vite, independiente y ejecutable.

| Carpeta | Contenido |
|---|---|
| experiencia-1 | Entorno de trabajo y primer componente (JSX y props) |
| experiencia-2 | Lista de tareas con props y useState |
| experiencia-3 | Formulario controlado y eventos |
| experiencia-4 | Carga inicial con fetch, estados de carga y error |
| experiencia-5 | Navegación con React Router (Inicio y Tareas) |
| experiencia-6 | Rutas anidadas, Outlet, useParams y detalle de tarea |

## Ejecución

```
cd experiencia-1
npm install
npm run dev
```

Repita los mismos comandos en la carpeta de cada experiencia.
