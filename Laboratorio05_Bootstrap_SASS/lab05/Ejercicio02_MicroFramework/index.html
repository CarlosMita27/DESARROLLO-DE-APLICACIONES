Micro-Framework CSS Modular

Sistema de diseño construido con Sass. Arquitectura basada en parciales semánticos, funciones matemáticas y abstracción de utilitarios.

1. Tipografía y Escalamiento (Función px-a-rem)

Este párrafo utiliza el tamaño de fuente base convertido dinámicamente a unidades rem mediante programación en Sass. Los márgenes inferiores también están automatizados para mantener el ritmo vertical.

este elemento se inspecciona para verificar que usa rem en lugar de px.

2. Componentes UI: Botones Automatizados

El color del texto se calcula automáticamente con la función lightness() para asegurar accesibilidad y contraste.
