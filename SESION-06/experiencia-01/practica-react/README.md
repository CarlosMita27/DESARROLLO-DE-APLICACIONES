# DevLab React - Experiencia N.° 01

Proyecto React (Vite) que resuelve la Experiencia N.° 01 del Laboratorio N.° 06:
creación y estructura de una aplicación React (Parte 1) y uso de JSX (Parte 2).

## Cómo ejecutar

Abrir una terminal (CMD) dentro de esta carpeta y ejecutar:

```bash
npm install
npm run dev
```

Luego abrir en el navegador la dirección que muestre la terminal
(normalmente http://localhost:5173).
