===== EXPERIENCIA 4: BASE DE DATOS MYSQL EN LA NUBE (TLS) =====
# Proveedor: Aiven for MySQL (plan Developer, DigitalOcean nyc). SSL mode: REQUIRED.
# Host: mysql-3bfd4f3d-carlosalberto1527m-e456.f.aivencloud.com  Puerto: 15472  CA: certs/ca.pem (descargado del panel)

# Cliente mysql con SSL verificado, usuario administrador del proveedor (avnadmin):
$ mysql -h <host> -P <puerto> -u avnadmin -p --ssl-mode=VERIFY_IDENTITY --ssl-ca=certs/ca.pem < sql/nube_base_usuario.sql
(base biblioteca y usuario biblioteca_app creados; la clave real está en .env)
$ mysql ... -D biblioteca < sql/biblioteca_nube.sql   (biblioteca.sql sin el bloque del usuario local)
